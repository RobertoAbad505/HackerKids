🧭 Overview

This project started as a personal portfolio, but evolved into a fully interactive iOS learning playground designed to demonstrate real iOS features, user interaction patterns, and modern SwiftUI architectures.

Rather than acting as a static presentation, the app provides hands-on experiences, mini-games, API-driven screens, gesture recognition, and system integrations that showcase how iOS technologies can be used in real-world scenarios.

The goal is twofold:

📚 Learn & experiment with iOS concepts

🧪 Demonstrate production-ready patterns and interactions

🎯 Purpose

This app is intended to:

Serve as an educational sandbox for iOS development

Demonstrate feature-based architecture

Showcase SwiftUI, Vision, networking, animations, state management, and UX

Provide interactive value to users, not just a static portfolio

Each module is self-contained and focuses on a specific technical or interaction concept.
